# Security policy

## Reporting a vulnerability

Please **don't** report security vulnerabilities as issues in this repository or through
**Send feedback** in the app. Both are published openly, so anyone could read your report before
the problem is fixed.

Report them privately instead, through GitHub:

1. Go to this repository's [Security tab](https://github.com/rejuve-bio/bioperformance-feedback/security).
2. Choose **Report a vulnerability**.
3. Describe the issue, how to reproduce it, and what it affects.

Only you and the maintainers can see the report, and the conversation about it stays there.

This covers the BioPerformance mobile and web apps and the service behind them.
