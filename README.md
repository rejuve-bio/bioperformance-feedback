# Feedback screenshots

Written by the BioPerformance feedback publisher. Don't edit, merge or rewrite this branch.

Each report's screenshots are in their own folder, `reports/<report-id>/screenshot-<n>.<png|jpg>`,
and the report's issue shows them by their raw URL on this branch. Rewriting, force-pushing or
deleting the branch would break the images in every issue that has been published.

This branch is never merged into `main`. See the
[README on `main`](https://github.com/rejuve-bio/bioperformance-feedback#readme) for what is
published and why.
